# Personal Portfolio Website

## 📌 About the Project
This project is a simple and responsive personal portfolio website developed using **HTML5 and CSS3**. It showcases my personal profile, skills, and basic information through a clean and user-friendly design.

The website consists of two pages that help visitors learn more about me and explore my portfolio.

## 📄 Pages Included
- **Home Page:** Introduces me and provides a brief overview of my profile.
- **About Page:** Displays personal information, skills, and other relevant details.

## 🛠️ Technologies Used
- HTML5
- CSS3

## ✨ Features
- Simple and clean user interface
- Two-page website navigation
- Basic CSS styling and layout
- Beginner-friendly web development project
- Easy-to-use design

## 🎯 Project Objective
The main objective of this project is to practice HTML and CSS fundamentals, understand webpage structure, and gain hands-on experience in building a personal portfolio website.

## 🚀 How to Run the Project
1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
